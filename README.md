# Unemployment Analysis with Python

This project analyzes unemployment data in India using Python and Streamlit.

## Project Features

- Data cleaning and preprocessing
- Unemployment rate analysis
- Monthly unemployment trends
- COVID-19 impact analysis
- State/Region and Rural/Urban comparison
- Monthly patterns and seasonal trends
- Labour market correlation analysis
- Basic policy and social insights

## Streamlit App

The app provides interactive charts and filters for exploring the unemployment data.

## Libraries

- Streamlit 1.48.1
- Pandas 2.3.2
- Plotly 6.3.0

## How to Run

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run the Streamlit app:

```bash
streamlit run app.py
```

Make sure `app.py` and `Unemployment in India.csv` are in the same folder.

## Dataset

The project uses the `Unemployment in India.csv` dataset.
